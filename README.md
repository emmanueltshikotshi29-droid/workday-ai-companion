# Workplace AI Assistant

A modern, AI-powered workplace productivity dashboard designed to help professionals streamline daily tasks, generate professional emails, organise schedules, conduct research, and receive contextual workplace assistance.

## Project Overview

Workplace AI Assistant is a responsive SaaS-style web application featuring a clean interface, deep teal and emerald accents, and an intuitive dashboard. It brings essential workplace productivity tools together in one platform.

The application uses AI to generate contextual responses based on user inputs, helping users save time, improve communication, and organise their work more effectively.

## Features Implemented

- **Dashboard Overview:** Productivity statistics, recent activity, and quick-access cards.
- **Smart Email Generator:** Generate professional emails in Formal, Friendly, Direct, and Persuasive tones, with editing, copying, tone adjustment, and regeneration.
- **AI Task Planner:** Create daily or weekly schedules based on tasks, deadlines, priorities, durations, and available hours. Edit tasks and track completion.
- **AI Research Assistant:** Summarise topics, questions, and pasted articles into executive summaries, insights, recommendations, and actionable takeaways.
- **Workplace Chatbot:** Interactive AI assistance for workplace questions, brainstorming, writing, research, and problem-solving.
- **Responsive Design:** Collapsible sidebar navigation and mobile-friendly layouts.
- **Local Storage:** Save email drafts, task lists, and appropriate user history across browser sessions.
- **AI Integration:** Dynamic AI-generated responses through a supported integration, with secure server-side calls and streaming where supported.
- **User Experience:** Editable output cards, copy-to-clipboard actions, loading indicators, input validation, and error notifications.
- **Responsible AI:** Disclaimer encouraging users to verify AI-generated content and avoid submitting confidential information.

## Setup Instructions

### Prerequisites

- Node.js and npm installed.
- Git installed.
- A GitHub account.
- Access to the configured AI integration, if required.

### 1. Clone the Repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/workplace-ai-assistant.git
cd workplace-ai-assistant
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

If your AI integration requires environment variables, configure them according to the provider’s instructions.

Example:

```env
AI_API_KEY=your_secret_api_key
```

Never expose secret API keys in frontend code or commit them to GitHub. Store secrets securely on the server side. If a managed integration handles authentication, follow its setup instructions instead.

### 4. Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, commonly `http://localhost:5173`.

### 5. Build for Production

```bash
npm run build
```

Optionally preview the production build:

```bash
npm run preview
```

## Responsible AI Disclaimer

AI-generated content may contain inaccuracies. Please review before professional use and avoid submitting confidential data.

Users should independently verify important facts, research findings, and recommendations before relying on them.

## Data and Privacy

- Drafts and tasks may be stored locally in the browser.
- Clearing browser storage may remove locally saved information.
- AI requests may be processed by the configured AI provider.
- Avoid submitting passwords, confidential company information, or sensitive personal data.
